# Personal Wishlist App

## Goal

A private web application for managing my personal wishlist.

## MVP Features

- Add wishlist items
- View wishlist items
- Edit wishlist items
- Delete wishlist items
- Categorize items
- Add price
- Add product URL
- Set priority
- Secure login

## Future Features

- Allow guests to access the wishlist
- Allow guests to reserve items
- Hide reservation identities from the wishlist owner

## Wishlist Item

Each item will contain:

- Name
- Description
- Category
- Price
- URL
- Priority
- Date added
